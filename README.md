# 🛡️ PDF Redactor Pro

Professional PDF redaction tool with Adobe compatibility.

## Features

- ✅ Redact sensitive information with white boxes
- ✅ Multi-page navigation
- ✅ Zoom controls
- ✅ Flattened PDF export (Adobe compatible)
- ✅ Keyboard shortcuts
- ✅ Cross-platform (Windows, macOS, Linux)

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run electron:dev

# Build for production
npm run electron:build
